{{ "How to Read: ROC Curve" if results.summary.task == 'CLASSIFICATION' else "How to Read: Residuals" }}
{% if results.summary.task == 'CLASSIFICATION' %}

The ROC curve plots the True Positive Rate vs. the False Positive Rate at various thresholds.

  • The Goal: A curve that "hugs" the top-left corner.
  • AUC (Area Under Curve): 1.0 is perfect; 0.5 is no better than guessing.
If the line is diagonal, the model is making random guesses.
{% else %}

Residuals show the distance between the model's guess and the actual truth.

  • Symmetry: Points should be balanced above and below the zero line.
  • Clusters: If points cluster at one end, the model may be biased for low or high values.
A random cloud is good; a visible "shape" means the model can be improved.
{% endif %}
{{ "Understanding: Confusion Matrix" if results.summary.task == 'CLASSIFICATION' else "Understanding: Predictions" }}
{% if results.summary.task == 'CLASSIFICATION' %}

This matrix tells you exactly which classes the model is confusing.

  • Vertical Axis: The actual true classes.
  • Horizontal Axis: What the model predicted.
  • Diagonal: These are the correct hits.

If one box off the diagonal is very dark/bright, that's a systematic error the model is making.

{% else %}

This plot places every prediction against its real value.

  • The Line: Represents the 45-degree "Identity Line" where prediction = truth.
  • Tightness: The closer the dots are to the line, the more accurate the model.

Look for outliers here to find edge cases where your data might be noisy.

{% endif %}
